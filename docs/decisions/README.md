# Decisions

Decisions about Wordsmith Manuscript's own behavior, one file each, numbered in order:
`NNNN-title.md` with four parts: **Context**, **Decision**, **Consequences**, **Revisit when**.
Decisions about interfaces shared by the foundation's apps go in open-source-core's
`docs/decisions/`, never here. From outside this repository a record here is cited as
"Manuscript decision 0003"; a record of the core is cited as "core decision 0011".

Each record's first line gives its date and status, in the form the core's records use:
`Date: … · Status: … · Amended …`. A record is amended with a dated line or section; its
reasoning is never rewritten. A record that no longer holds says which record replaced it. The
table shows each record's status; change both together.
